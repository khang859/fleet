# PR 557 review: creation and settings state

Reviewed commit `1da025c8fb59156118bca4cc22ee79a11a2a7bda`. All four findings were confirmed and fixed in the follow-up commit on the same branch.

## Creation persists an override without refreshing renderer settings

A temporary integration check loaded renderer settings, persisted a new workspace with a custom folder, then refreshed the workspace list exactly as the creation dialog does. The main-process settings contained the custom folder, but the renderer still resolved the workspace to the default folder. Explicitly reloading renderer settings corrected the displayed assignment.

The creation success path needs to refresh settings before presenting the new row and its folder-specific hook actions. Refreshing workspace metadata does not refresh configuration.

## A draft source choice must remain separate from the saved source

A temporary component check selected “Use custom folder” for a workspace inheriting the default. The custom input appeared, but the controlled radio props still selected Default. Blurring the empty custom input removed its draft and unmounted the input and Browse button.

Keep the selected editing mode separately from the persisted override. Empty drafts must not silently dismiss custom mode, particularly during a focus transition to Browse.

## Dismissal does not cancel pending creation

A temporary component check delayed layout persistence, submitted creation, clicked Cancel, closed the dialog, and then completed persistence. The old request still invoked `onCreated`. In the sidebar that callback switches workspaces, so a dismissed dialog can later interrupt current work.

Guard dismissal while creation is pending, or explicitly invalidate completion callbacks when the dialog closes. Account for Escape and backdrop dismissal as well as the Cancel button.

## Hook IPC is only registered on macOS

`initCopilot` returns before registering hook IPC on Windows and Linux. The new unconditional default-folder `FolderHooks` control nevertheless invokes those handlers whenever Workspaces settings mounts.

Gate hook controls by runtime support while retaining workspace creation and configuration editing on all platforms. A missing runtime should not appear as a filesystem check failure.

## Validation

The existing six focused suites passed (112 tests), and typechecking passed. Three temporary review reproductions confirmed the stale renderer configuration, draft-mode behavior, and post-dismissal creation callback. Those temporary files were removed after review; the scenarios should become regression tests alongside the fixes.
