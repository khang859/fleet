Built-in Agent

A coding agent already on board

Fleet runs its own agent chat in a pane, right next to your terminals. Bring one OpenRouter key, pick any model per conversation, and approve every action before it touches your machine.

Any model, one key
Flight Plan

Choose from the whole OpenRouter catalog per conversation, pin the providers you trust, and fall through to a backup when one is down. A spend meter shows what the turn cost as it runs.

Real tools, gated
Rules of Engagement

Read, write, edit, grep, glob, shell, web fetch, and web search. Anything that touches your files or runs a command asks first - allow it once or for the session.

Subagents & to-dos
Away Team

Hand a side quest to a subagent that works in the background and reports back, while a to-do panel keeps the plan for the main thread visible.

MCP servers
Docking Ports

Import the MCP setup you already have from Claude Code. Tools are searched for when they are needed, so a large toolbox never crowds out the conversation.

Skills & memory
Standing Orders

Markdown skills, slash commands, and project instructions the agent picks up on its own - plus memory it can write to and read back in a later session.

Second opinions & panels
War Room

The coding model can consult a stronger one mid-turn, inside a budget you set. Or run /fusion to put the same change in front of several models at once.

Images & voice
Visual Ops

Generate and edit images inside the thread; a cross-session Images tab keeps every one with its prompt. Speak into the composer when typing is the slow part.

Scratch & schedules
Standing Watch

Cmd+Shift+J opens a chat with no project attached, in a folder of its own. Give a prompt a schedule and it fires on its own, with the answer waiting in the thread.

Features

What's on board

The terminal around it: everything you need to run Claude Code, Codex, or any other agent from one window.

01
Tabs & Workspaces
Tactical Command

Organize agent sessions with draggable tabs and persistent workspaces that survive restarts.

02
Split Panes
Formation Control

Divide your terminal into any layout - horizontal, vertical, or nested splits.

03
Telescope Finder
Recon Scope

Multi-mode fuzzy finder for files, grep, symbols, and directory browsing. Images preview inline; gitignored entries dim out.

04
Activity Badges
Signal Detection

See agent status at a glance - amber for permission needed, blue for done, red for errors. The same alerts reach your OS, batched so they never pile up.

05
Git & Worktrees
Supply Lines

Branch labels on every tab, file-level diffs with syntax highlighting, and worktrees grouped by parent repo.

06
Editors & Viewers
Reading Room

Open files in a CodeMirror editor with syntax highlighting and auto-save. Markdown gets a preview pane, and images and PDFs open inline - each one nested under the session you opened it from.

07
Command Palette
Quick Orders

Access any action instantly with Cmd+Shift+P. No menus, no hunting.

08
Clipboard History
Intel Archive

Pull up previous clipboard entries with Cmd+Shift+H across all your sessions.

09
Annotate
Recon Photos

Mark up a live webpage with an element picker or free-draw canvas, then hand the annotated screenshot straight to an agent.

10
SSH Panes
Long Range

Copy out of vim on a remote host into your own clipboard, drop a file on the pane to upload it where you are standing, and pull one back with fleet get.

11
CLI & Socket API
Remote Control

A fleet command opens files and panes from any shell, and a local socket lets scripts list panes, send input, and subscribe to events.

12
Auto-Updates
Resupply

Fleet checks for new versions on a schedule, on focus, and on wake - then asks before it stops anything you have running.
